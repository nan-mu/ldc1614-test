# ldc1614

Provide a user-friendly interface for Texas Instruments' LDC1614 chip, compatible with version 1 of embedded-hal. Reference ![ldc1x1x](https://docs.rs/ldc1x1x/) for development. Use tock-registers to offer a more 'Rust' design, with future plans to achieve the same level of support as ![ldc1x1x](https://docs.rs/ldc1x1x/).

[`embedded-hal`]: https://docs.rs/embedded-hal
[LDC1312/LDC1314]: https://www.ti.com/lit/ds/symlink/ldc1314.pdf
[LDC1612/LDC1614]: https://www.ti.com/lit/ds/symlink/ldc1614.pdf
