# 已知寄存器的值

| 寄存器          | 数据手册    | 学长的               |
|-----------------|-------------|----------------------|
| RCOUNTx         | 0x04d6      | 0xffff               |
| OFFSETx         | 0x0000      | 0x0000               |
| SETTLECOUNTx    | 0x000a      | 0x0400               |
| CLOCK-DIV       | 0x1002      | 0x0000               |
| STATUS          | 0x000       | 0x0001               |
| ERROR-CONFIG    | 0x0000      | 0x0200               |
| CONFIG          | 0x1601      | 0x0200               |
| RESET-DEV       | 0x0000      | 0x8000               |
| MUX-CONFIG      | 0x020c      | 0x820f or 0xc20f     |
| DRIVE-CURRENTx  | 0x9000      | 0x0000               |
